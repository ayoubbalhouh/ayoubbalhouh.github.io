# Grano Nero · E-commerce demo

Negozio online demo per una torrefazione artigianale, realizzato da **Ayoub Balhouh**.

## Funzionalità
- Catalogo con filtri per categoria, ricerca e ordinamento
- Scheda prodotto con scelta della quantità
- Carrello laterale salvato nel browser (localStorage)
- Barra di avanzamento per la spedizione gratuita
- Checkout con validazione del form e conferma d'ordine
- Layout responsive (desktop, tablet, mobile) e navigazione da tastiera

## Tecnologie
HTML5, CSS3 (Grid, Flexbox, variabili CSS), JavaScript vanilla (ES6+). Nessuna libreria esterna.

## File
- `index.html`: struttura della pagina
- `style.css`: stile e responsive
- `products.js`: catalogo prodotti
- `app.js`: logica del negozio (filtri, carrello, checkout)

> Progetto demo: nessun ordine o pagamento reale.
