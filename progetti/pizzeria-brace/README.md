# Brace · Pizzeria napoletana

Sito con ordine online per una pizzeria, realizzato da **Ayoub Balhouh**.

## Funzionalità
- Menu per categorie con tab che si aggiornano durante lo scroll
- Aggiunta al carrello con un tocco e quantità modificabile direttamente dalla card
- Barra dell'ordine sempre visibile e pannello laterale
- Asporto o consegna (ordine minimo e costo di consegna)
- Fasce orarie calcolate in base agli orari di apertura e all'ora attuale
- Stato "Aperto ora / Chiuso" automatico
- Pizze disegnate in SVG con JavaScript a partire dagli ingredienti
- Carrello salvato nel browser, layout responsive, rispetta "riduci animazioni"

## Tecnologie
HTML5, CSS3, JavaScript vanilla. Nessuna libreria.
